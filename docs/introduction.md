# taktsim documentation

taktsim simulates production lines from a text file: you describe the
machines, how long each step takes and how much can wait between them, and
taktsim plays out a shift, a week or a year and reports what comes out, with
confidence intervals. The [README](https://github.com/taktsim/taktsim#readme)
gives the overview and the current status: taktsim is pre-release and cannot
run a model yet.

- **New to production lines?** Start with the
  [Concepts](concepts/index.md): a learning path from stations and buffers
  to simulation results you can trust.
- **Want the details?** The [specification](spec.md) says what taktsim
  will do, the [roadmap](roadmap.md) when, and the
  [architecture decisions](adr/) why.
